Connections

Links the site to your database, so the counter is shared by everyone and orders reach your WhatsApp.

Database

Find both in Supabase under Project Settings, API. The anon key is safe to publish, your tables are locked down so it cannot read orders or change the counter directly.

One time setup, about fifteen minutes
  1. Create a free account at supabase.com and start a new project. Pick a region near Lebanon, such as Frankfurt.
  2. Open the SQL Editor, paste in the whole supabase-setup.sql file, and press Run.
  3. Get your WhatsApp key: add +34 644 51 95 23 to your contacts, send it the message I allow callmebot to send me messages, and it replies with your API key.
  4. In the SQL Editor, scroll to the last block of the file, put in your phone number, that API key, and a passphrase of your choosing, then run just that block.
  5. Go to Project Settings, API, copy the Project URL and the anon key into the two boxes above.
  6. Download content.json and upload it to GitHub.

Publish your changes

How to take what you edited here and make it live.

Editing here does not change the live site on its own. You download the updated file and upload it to GitHub, which takes about a minute.
Every time you make a change
  1. Press Preview site to check it looks right.
  2. Press Download content.json. The file lands in your Downloads folder.
  3. Go to your repository on github.com and open the content.json file.
  4. Click Add file, Upload files in the main folder, drag in the new content.json, and click Commit changes.
  5. If you changed images, also upload the new image files into the assets folder the same way.
  6. Wait about a minute and refresh your website.
